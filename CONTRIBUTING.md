# Contributing

Add documented, publicly accessible MCP servers that implement the Model Context Protocol.

## Add a Server

1. Choose the most relevant existing category.
2. Add the server in alphabetical order.
3. Use `- [Name](link) - Brief description.`
4. Link to durable documentation or a repository with setup instructions.
5. Describe the current transport and authentication requirements accurately.
6. Run a Markdown link check and `git diff --check`.
7. Open a focused pull request with your validation evidence.

Add a new category only when no existing category fits. Update the table of contents in the same change.

## Quality Requirements

- Confirm the server and documentation are publicly reachable.
- Keep descriptions factual, concise, and free of unverifiable claims.
- Disclose your relationship when submitting your own project.
- Distinguish maintained servers from archived reference implementations.
- Do not include credentials, private endpoints, referral links, or tracking parameters.
- Address maintainer feedback on the existing pull request instead of opening duplicates.

By contributing, you agree that your changes are available under the license stated in the repository README.
